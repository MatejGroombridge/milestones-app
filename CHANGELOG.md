# Changelog
All notable changes to Milestones. Format roughly follows
[Keep a Changelog](https://keepachangelog.com). The most recent release is at
the top. Each entry is consumed verbatim by the release pipeline and shown to
users on the app's detail screen in the Groom Hub. Note that this blurb runs
on directly under the heading with no blank line above it — `bin/changeset`
inserts each new entry at the first blank line after the H1, so anything
placed below that point gets swallowed into the published release notes.
